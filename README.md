# Email Extractor (Manifest V3 Compatible)

The Email Extractor extension is a simple and efficient tool for your Chrome browser that allows you to quickly extract email addresses from the active web page. 

## Core Functionality

When you click the extension's icon in the Chrome toolbar, it opens a popup window displaying a list of all unique email addresses found. The extension extracts emails from two primary sources on the page:

1.  **HTML Content**: It scans the page's visible and underlying HTML structure for email patterns.
2.  **`mailto:` Links**: It specifically identifies and extracts email addresses from `mailto:` links.

## Key Features

*   **Manifest V3 Compatible**: Updated to the latest Chrome extension platform for enhanced security and performance.
*   **Accurate Extraction**: Utilizes an improved regular expression to more reliably identify and extract email addresses from page content.
*   **`mailto:` Link Support**: Now capable of finding and extracting emails directly from `mailto:` anchor links.
*   **Refreshed UI**: The popup window has been updated for a cleaner and more user-friendly experience.
*   **Email Count**: Displays the total number of unique email addresses found at the top of the popup.
*   **Copy All Emails**: A convenient "Copy All" button allows you to copy all unique extracted emails to your clipboard with a single click, formatted with one email per line.

This tool is particularly useful for quickly gathering contact information from websites without manually sifting through text or source code. The extracted emails are presented in a clear list within the extension's popup for easy viewing and copying.
